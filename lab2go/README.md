# Лабораторная работа 2

**Тема:** Условия, циклы, строки, структуры и методы в Go.

## Задания

1. **task2-1** — программа, которая определяет, является ли введённое пользователем число чётным или нечётным.
2. **task2-2** — функция, которая принимает число и возвращает `"Positive"`, `"Negative"` или `"Zero"`.
3. **task2-3r** — программа, которая выводит все числа от 1 до 10 с помощью цикла `for`.
4. **task2-4** — функция, которая принимает строку и возвращает её длину.
5. **task2-5** — структура `Rectangle` с методом для вычисления площади прямоугольника.
6. **task2-6** — функция, которая принимает два целых числа и возвращает их среднее значение.


## Требования

- Go 1.21 или новее.

## Запуск

Из корня репозитория:

```bash
go run ./lab2/task2-1
go run ./lab2/task2-2
go run ./lab2/task2-3
go run ./lab2/task2-4
go run ./lab2/task2-5
go run ./lab2/task2-6
```

Или из папки конкретного задания:

```bash
cd lab2/task2-1
go run .
```

## Сборка всех заданий сразу

```bash
go build ./lab2/...
```

## Что демонстрирует работа

- условные конструкции `if/else` и `switch`;
- цикл `for` в разных формах;
- работу со строками и подсчёт длины (через `utf8.RuneCountInString` для корректной работы с кириллицей);
- объявление структур и методов с value-ресивером;
- функции с несколькими параметрами и возвращаемым значением;
- ввод данных через `fmt.Scan`.
