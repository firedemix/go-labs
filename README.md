# go-labs

Лабораторные работы по курсу «Прикладное программирование».

**Студент:** Долгов Леонид Сергеевич
**Курс:** 3

## Структура

- `lab1/` — Лабораторная работа 1. Основы: типы, арифметика, функции.
- `lab2/` — Лабораторная работа 2. Условия, циклы, структуры.

## Требования

- Go 1.21+

## Как запускать

Каждое задание — отдельная папка со своим `main.go`:

    go run ./lab1/task1_time
    go run ./lab2/task5_rectangle

## Сборка всех лаб

    go build ./...
