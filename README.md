# go-labs

Лабораторные работы по курсу «Прикладное программирование».

**Студент:** Долгов Леонид Сергеевич
**Курс:** 3

## Структура

- `lab1go/` — Лабораторная работа 1. Основы: типы, арифметика, функции.
- `lab2go/` — Лабораторная работа 2. Условия, циклы, структуры.

## Требования

- Go 1.21+

## Как запускать

Каждое задание — отдельная папка со своим `main.go`:

    go run ./lab1/task1
    go run ./lab2/task5

## Сборка всех лаб

    go build ./...
