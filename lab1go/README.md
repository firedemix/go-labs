# Лабораторная работа 1

## Задания

1. `task1_time` — вывод текущей даты и времени
2. `task2_types` — переменные разных типов (int, float64, string, bool)
3. `task3_short` — краткая форма объявления переменных
4. `task4_arith` — арифметические операции с двумя int
5. `task5_float` — сумма и разность двух float64
6. `task6_average` — среднее значение трёх чисел

## Запуск

Из корня репозитория:

    go run ./lab1/task1_time

Или из папки задания:

    cd lab1/task1_time
    go run .
